## 验收标准
- 正式完成组仅来自 Facts/Review，不能直接依据识别文本加一组
- Pending 可见且有原因；无法确认时不伪装“已记账”
- 网络中断、模型超时、重试、完成但无事实各状态可复现
- 无网络/模拟演示时清楚标示 Mock，不冒充真实 AWS 或真机

## 目标
将 soundcore 录音豆 SDK 的真实音频输入转换为相同 WAV 契约，向上层屏蔽编码与断线差异。

## 必须交付
- 隔离的 SDK Adapter 与状态机
- SDK 实际回调/编码/采样率说明及转换器
- 配对、连接、断线重连、录音开始/结束演示
- 至少一个真实录音豆产生的授权 WAV 及验证证据

## 验收标准
- 真机 SDK 音频链可见且格式核验通过；若官方 SDK 不支持所需功能，明确阻断证据
- 模拟设备输入与真实硬件分开标识，绝不虚报 soundcore 已接入
- 断线时有可恢复错误状态，不自动产生完成训练组
- 音频时间戳、顺序及合并策略与 BackendHTTPClient 约定一致

## 注意事项
不要假设 SDK 一定支持 Android；安卓另行评估。

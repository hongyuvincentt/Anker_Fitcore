## 目标
在已有7段历史音频之外，形成跨说话者、设备/噪声的授权样本，不默认旧录音可再分发。

## 必须交付
- 目标约3–5人、约40段的授权 WAV 和非公开保存位置（目标非已完成）
- 每条录音的 consent_id、化名 speaker_id、录制设备、场景、SHA-256 和音频格式报告
- 原音频不可变；失败和撤销情况的记录
- 采样覆盖矩阵：动作、重量数字、重复次数、纠错、计划、噪声

## 验收标准
- 每段有可核实的授权记录，覆盖云端模型调用/团队共享范围
- 16k mono PCM16、WAV有效性、非空、长度/体积标准经过工具验证
- 每段 SHA-256 与 manifest 一致，原始文件不被覆盖或替换
- 撤销样本从待评测队列排除；不得上传私人录音至公共仓库

## 注意事项
既有连续训练7段为历史资料，不代表可自由向所有合作方共享。

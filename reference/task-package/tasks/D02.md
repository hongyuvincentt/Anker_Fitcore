- **负责人（本次交接后）：** LHY
- **原负责人：** 你+TRAE
- **协助/审查：** TRAE 提供语义字段建议；你/Codex 抽查与冻结
- **优先级：** P0
- **建议阶段：** 比赛前优先

- **代码或清单仓库：** `fitcore-coordination（脱敏标注）`

## 目标
产出人工参考文本与训练事实标签作为独立标准，不依据模型预测偷偷修正人工答案。

## 必须交付
- 标注规范及数据字典
- 逐条 reference_text、意图、动作、重量、次数、上下文/歧义/说话者标签
- 可追溯的 revision、annotator_id、reviewer_id 与争议裁决日志
- 双人抽检或由你/Codex复核的不一致列表

## 验收标准
- 原音频/ASR输出/人工真值分别存储
- 原始标准变更必须有原音频证据和审核记录，不得为提高模型得分修改金标
- 模糊语音允许 UNKNOWN/needs_audio_review，不得捏造重量或次数
- 标注不包含录制者姓名、电话、联系方式

## 注意事项
LHY 是主执行和数据责任人；算法端只能提交反馈与纠错申请，不能直接改锁定标签。

- Mock/真机/真实模型类型：待填

- 阻断与下次交接时间：待填

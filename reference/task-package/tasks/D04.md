# D04 · 独立 Held-out 测试集建设

- **领域：** 语料评测
- **负责人（本次交接后）：** LHY
- **原负责人：** 你+TRAE
- **协助/审查：** Codex/你负责冻结核验，TRAE不得基于测试真值调参
- **优先级：** P1
- **建议阶段：** 赛后／比赛前有余力
- **当前证据状态：** 待验收／实际进度待核查
- **代码或清单仓库：** `fitcore-coordination（受限访问）`
- **依赖：** D01、D03；审核人独立于调参方

## 目标
按说话者、会话、录制环境隔离测试集，防止7段旧样本反复调参造成虚高泛化指标。

## 必须交付
- speaker/session/scene 维度的 split 清单
- held-out 音频与标签文件哈希
- 冻结时间戳、访问记录及变更审批流程
- 污染/交叉重复检测报告

## 验收标准
- 同一 speaker/session 不跨 train 与 held-out（除非明确的另立评测设计）
- 冻结后的 held-out 不进入开发 prompt/回归调参集
- 样本数量与覆盖分布有明确分母；不足时标记“探索性”而非声称泛化
- 异常解封/重标由你或 Codex 独立审批

## 注意事项
LHY 主负责建立和维护，但必须有人独立核对和批准冻结；不能自己收集、自己调参又自行宣布独立测试通过。

## 提交回执（由LHY填写）
- Git branch / commit / PR：待填
- Xcode 或 Python 检查结果：待填
- Mock/真机/真实模型类型：待填
- 证据位置（不含密钥或私人音频）：待填
- 阻断与下次交接时间：待填
- 复核人：待填
